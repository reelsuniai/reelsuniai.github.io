# Why vibe-coded apps get sued: storyboard

## Invention
**Central metaphor: the app goes on trial.** Each of the four ways becomes a numbered courtroom EXHIBIT (A, B, C, D) tag that
swings onto an evidence board; the fourth stays SEALED in an evidence envelope (the curiosity loop) and tears open in its own
section. The verdict closes with a gavel and a nameplate that swaps "WRITTEN BY AI" for "DEFENDANT: YOU".
Why it fits: "get sued" = court; "four ways" = exhibits in the case against you; the gavel IS "to the law, it's yours".

Props (all drawn for this reel): weekend laptop + launch phone + calendar tiles (SAT/SUN/MON) + SUMMONS envelope · evidence board
with pins, red yarn and exhibit tags · screen-reader focus ring + speech bubble + scanner lens + falling label stickers ·
email envelope + data jar + "policy says / app does" ledger + 404 page · tracker pixel bug + data beam + chat widget + missing
consent banner + session-replay trail + REC pill · database drum with a vault door + empty padlock slot + link chip + strangers +
fountain of user rows · jury box of users + AI-written code card + gavel + DEFENDANT nameplate.

Wow moments: hook: the SUMMONS slams onto the freshly launched phone and cracks it; board: red yarn from sealed D hits a wall of
app tiles that flip red ("almost everyone": one stays white); A: the scan beam pops red flags while labels fall off; D: the vault
swings open and user rows fountain out to strangers; verdict: gavel slam swaps the nameplate.

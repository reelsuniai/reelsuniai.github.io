# The 50-thumbnail prompt (DM this to people who comment THUMBNAIL)

Copy this into Claude:

```
You are a YouTube thumbnail strategist.

My video: [one sentence about the video]
The payoff: [what the viewer gets / the most surprising moment]
My title: [title]

Give me 50 thumbnail concepts in a table. Change ONE thing at a time so I can test them:
- 10 that change only the FACE (emotion: shock, smile, focus, fear, smirk…)
- 10 that change only the COLORS (background + accent)
- 10 that change only the TEXT (2–4 words, never repeating the title)
- 10 that change only the OBJECT/PROP in frame
- 10 bold wildcards

For each: emotion · main object · background colour · text on thumbnail · why it creates curiosity.
Then pick the top 3 to A/B test first (YouTube Studio → Test & Compare) and explain why.
Include at least 3 closed-mouth face versions.
```

Tip: test only 2–3 at a time with YouTube's Test & Compare, keep the winner, then test the next variable.

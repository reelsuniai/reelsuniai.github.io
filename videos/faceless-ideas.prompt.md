# The full prompt (DM this to people who comment IDEAS)

Copy this into Claude:

```
You are a YouTube strategist for faceless channels.

Give me 5 faceless channel ideas that are NOT saturated yet. For each idea:
1. The niche in one line, and why it isn't crowded yet.
2. The format: what every video looks like (length, visuals, voice), so I can make it without showing my face.
3. 3 example video titles that would make someone stop scrolling.
4. How hard it is to make one video (easy / medium / hard) and what tools I'd need.
5. How it makes money (ads, sponsors, affiliate, products) and whether advertisers pay more for this topic.

Then pick the ONE you would start if you were me, and explain why in 3 sentences.
Finish with a 7-day plan to publish the first 7 Shorts for that channel.

My situation: [your time per week], [your skills: editing / writing / drawing / none], [your language], [Shorts or long videos].
```

Tip: answer the last line honestly. The ideas get much better when Claude knows how much time you have.

# /shorts-script

Target: 20–30 s spoken ≈ 60–90 words at a natural pace.

Structure (in this order):
1. **Hook** (≤ 9 words): the payoff or a surprise, no warm-up.
2. **Loop** (sentence 2): promise something the ending pays off.
3. **Body**: one idea per sentence, each sentence = one clear visual. Lists: say the count first, then "One… Two… And the last one…".
4. **Payoff**: close the loop with the most useful point.
5. **CTA**: "Comment KEYWORD and I'll send you …" (KEYWORD = one uppercase word tied to the topic).

Rules: conversational, contractions, 8–18 words per sentence, numbers over adjectives, "you" over "people", no corporate words, only facts you're sure of.

Output:
- The script
- Word count + estimated length
- A shot list: one line per sentence saying what's on screen
- 3 caption lines + 5 hashtags

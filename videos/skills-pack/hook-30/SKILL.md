# /hook-30

1. Get the topic and the payoff (what the viewer gets). Ask once if missing.
2. Write 5 hooks, each **9 words or fewer** (under 3 s spoken), each from a different pattern:
   - Result first ("This free tool writes my scripts.")
   - Mistake ("Stop doing X if you want Y.")
   - Curiosity gap ("Nobody tells you this about X.")
   - Challenge/experiment ("I let Claude run my channel for 7 days.")
   - Steal this ("Steal the prompt that does X.")
3. Score each 1–10 on: clarity in 1 second, curiosity, specificity, fit with the payoff. Show the total.
4. Pick the winner and write the **sentence 2 loop** for it (a promise that only pays off at the end, e.g. "and the last one is the one I actually use").
5. Say what must be **on screen in frame 0** for the winner.

Never use: "Hey guys", "In this video", "POV:", questions as hooks, time-of-day openers.

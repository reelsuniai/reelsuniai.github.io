# ShortsUniversity: 6 YouTube skills for Claude

Install: put each folder in your Claude skills folder (Claude Code: `~/.claude/skills/<name>/SKILL.md`; Claude app: Settings → Capabilities → Skills → upload). Then type the command, e.g. `/hook-30 claude for youtube`.

| Command | What it does |
|---|---|
| /viral-topic | 10 proven topics in your niche, rewritten as your angle |
| /hook-30 | 5 hooks under 3 seconds, scored, with the loop line |
| /shorts-script | A 20–30 s script with hook, loop, payoff and CTA |
| /title-thumb | Title + thumbnail text that don't repeat each other |
| /retention-fix | Reads your retention graph and tells you what to fix |
| /repurpose | 3 Shorts with timecodes from one long video |

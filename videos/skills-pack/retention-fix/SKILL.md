# /retention-fix

1. Read what the user gives: retention graph, skip rate, average watch time, length, and the script if available.
2. Find the **drop points**: the second(s) where the curve falls fastest. For Reels, the first 3 s matter most; a skip rate above ~50% means the opening failed.
3. Match each drop to what was on screen / being said at that moment (ask for the script if needed).
4. Diagnose with one cause per drop, e.g.:
   - Slow opener (setup before payoff)
   - Empty or small first frame
   - Flat stretch (nothing changes for 2+ s)
   - Video too long for its idea
   - Loop never opened, so nothing to wait for
5. Give fixes, most impactful first: rewritten first sentence, what to show in frame 0, what to cut, target length.
6. Say which numbers are good and must be kept (saves, shares, comments).

Be direct and specific. Never invent numbers the user didn't give.
